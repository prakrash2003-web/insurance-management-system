About this project

The Insurance Management System is a Django demo application that models a small insurance provider. Customers can browse and compare policies, receive a transparent rule-based recommendation, apply for cover, submit claims and renew approved policies. Administrators manage the policy catalogue and review applications, questions and claims.

It is built with Django 4.2, uses role-based access control (customer vs. staff), environment-based configuration and an automated test suite.
